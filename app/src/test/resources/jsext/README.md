`wordrain69.js` is an unmodified Mangayomi extension, copied from
https://github.com/kodjodevf/mangayomi-extensions (Apache License 2.0), used to prove that the
JS engine in `org.koitharu.kotatsu.jsext` runs real extensions.

The HTML files under `wordrain69/` are synthetic: small pages written to match the selectors that
extension uses. They are not copies of the live site.
